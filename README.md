# MediaTracker

**MediaTracker** — офлайн-приложение для организации и отслеживания потребления медиаконтента.  
Поддерживает фильмы, сериалы, книги, игры, подкасты, музыку и другие типы медиа.  
Главная цель — дать пользователю гибкий инструмент для учёта прогресса и персональных заметок.

---

## 🎯 Основная концепция

MediaTracker работает как **персональная библиотека медиа**, где каждый пользователь может:
- хранить список просмотренного/прочитанного/прослушанного/пройденного контента;
- группировать элементы по циклам, франшизам и вселенным;
- отслеживать прогресс в составных медиа (сезоны, главы, треки, выпуски);
- использовать гибкие **статусы** и **теги**, настраивая их под себя.

---

## 🧩 Типы медиа

Все медиа делятся на 4 **основных типа потребления**:
- **Текст**: книги, статьи, манга, веб-комиксы.  
- **Видео**: фильмы, сериалы, короткие видео, спектакли.  
- **Аудио**: музыка, подкасты, альбомы.  
- **Интерактивные**: игры, образовательные курсы.  

### По структуре:
1. **Единичные медиа** — завершённые элементы (фильм, книга, сингл).  
2. **Составные медиа** — состоят из связанных частей (сериал → сезоны, книга → цикл, подкаст → выпуски).  
3. **Особые случаи** — вселенные (Marvel, Ведьмак), объединяющие разные типы медиа.

## 🗂 Архитектура данных

### Пользователи
Каждый пользователь имеет:
- собственные записи медиа,
- собственные кастомные статусы,
- собственные теги.

---


### Основные сущности и их описание 

- **User** — владелец библиотеки.  
- **Universe** — объединяет несколько групп (например, Marvel).  
- **Group** — франшиза, цикл книг или серия игр.  
- **MediaItem** — конкретное произведение (фильм, книга, игра).  
- **SubItem** — часть составного медиа (сезон, эпизод, том, трек).  
- **CoreStatus** — базовое состояние (в плане, в процессе, завершено, брошено и т.д.).  
- **UserStatus** — персонализированное название статуса для конкретного пользователя и типа медиа.  
- **Tag** — персональный ярлык («избранное», «повтор», «жду продолжение»).  
- **MediaItemTag** — связь медиа и тегов.

---

## 🏷 Система статусов

**CoreStatus (фиксированные):**
- planned (в плане)  
- on_hold (отложено)  
- dropped (брошено)  
- waiting (жду выхода)  
- in_progress (в процессе)  
- finished (завершено)  

**UserStatus (кастомизация):**
- пользователь может переименовать статус под свой стиль,  
- для разных типов медиа — разные названия (книга: «прочитано», фильм: «просмотрено», игра: «пройдено»).  

---

## 🏷 Система тегов

- Каждый пользователь может создавать **свои теги**.  
- Один медиа-объект может иметь несколько тегов.  
- Примеры: «избранное», «повтор», «жду продолжение».  
- Теги можно использовать для фильтрации и поиска.

---

## 🎯 MVP-версия

В первой версии (MVP) планируется:
1. Поддержка нескольких пользователей.  
2. Добавление медиа-объектов с типами (текст, видео, аудио, интерактив).  
3. Группировка по сериям/франшизам (Group) и вселенным (Universe).  
4. Учёт прогресса по SubItem (например, сколько серий просмотрено).  
5. Система статусов (CoreStatus + UserStatus).  
6. Система персональных тегов.  
7. Поиск и фильтрация по title, type, status, tags.  
8. Импорт/экспорт библиотеки (JSON).
