# MediaTracker

## 📊 О проекте
MediaTracker — это комплексное приложение для организации и отслеживания потребления различного медиаконтента, включая фильмы, сериалы, мультфильмы, аниме и компьютерные игры. Приложение позволяет пользователям категоризировать контент, добавлять комментарии и заметки, а также отслеживать свой прогресс в просмотре или прохождении.
